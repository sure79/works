# 아침 뉴스 브리핑

독자: 선박 전장(전력계통·전기추진·배터리 ESS) 설계를 하는 수석연구원. 조선·해운 현업 관점에서
"오늘 알아야 할 것"만 빠르게 파악하고 싶어 한다.

## 입력

프롬프트 앞부분에 `fetch_news.py` 스크립트 출력(분야별 헤드라인 + 링크 목록)이 들어온다.
- 이 목록을 1차 자료로 사용한다.
- 목록이 비었거나 "수집 오류"가 많으면 `web_search` 도구로 같은 분야를 직접 검색해 보충한다.
- 중요한 기사 1~2개는 필요하면 `web_extract`로 본문을 확인해 요약 정확도를 높인다.

## 선별 기준

1. 분야별로 가장 의미 있는 기사 3~5개만 고른다. 같은 사건을 다룬 기사는 하나로 합친다.
2. 우선순위: 실제 수주·규제(IMO, KR/DNV 선급, 국내 정책)·신제품·기술 발표 > 투자·실적 > 단순 행사·홍보.
3. 선박 전장 분야는 전기추진, 하이브리드, 배터리 선박, 배전반, 육상전원(AMP), 친환경 연료 선박 전력계통을 우선한다.
4. 제목만으로 내용을 지어내지 않는다. 확인이 안 된 내용은 "제목 기준" 이라고 표시한다.

## 출력 형식 (텔레그램 메시지, 한국어)

```
🌅 YYYY-MM-DD(요일) 아침 브리핑

⚓ 선박 전장
• 한 줄 요약 — 왜 중요한지 한 구절 (출처)
  링크

🔋 배터리
• ...

🤖 AI
• ...

💡 오늘의 한 줄 인사이트
실무(선박 전력계통 설계·사업)에 연결되는 시사점 1~2문장
```

- 전체 길이는 3,000자 이내로 한다.
- 표나 복잡한 Markdown은 쓰지 않는다(텔레그램 가독성).
- 링크는 스크립트가 준 URL을 그대로 사용한다.
